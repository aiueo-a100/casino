  1. 上の「ガチャ」で、実際に引いたガチャを選びます(超ネコ祭と通常では排出率が違います)。
  2. レアチケットまたはネコカン150で引いた結果を、引いた順に選びます。7〜10体あるとほぼ1つに決まります。
  3. 11連を引いたときは、1〜10体目を普通に選び、11体目の超激レアは「確定枠」グループから選びます(15連ステップアップは最後の1体)。

    レア 激レア 超激レア 伝説レア 次に引く位置 単発で通る位置 11連で得る位置 →5B = そこを引いた後の位置／「被り時」= 直前と同じレアだった場合に代わりに出るキャラ／「11連」= そこから11連を引いたときの確定枠

    使い方

    1. ガチャを選ぶ: 画面上部の「ガチャ」で、実際に引いた(引く予定の)イベントを選びます。「詳細」で排出率と排出テーブルが見られます。
    2. シードを調べる: 7〜10回引いた結果を順番に選んで「シードを検索」。候補が1つなら「このシードでテーブルを見る」を押します。複数のときは、あと1〜2回引いて結果を追加し、再検索してください。
    3. テーブルを読む: Aの一番上(▶次)が次に引けるキャラです。実際に引いたら、そのセルを押して「ここまで引いた」を選ぶと位置(シード)が進みます。11連を引いたときはセルを押して「11連を引いた」を選びます。間違えたら「1つ戻す」。
    4. 評価と取り方: テーブル上のカードに、次の30回の超激レアの数をそのガチャの平均と比べた評価(大当たり/かなり良い/良い/普通/やや悪い/悪い)と、「一番の当たり」(伝説レア → 狙いのキャラ → 一番近い超激レア)までの最短の取り方が出ます。「狙いのキャラ」を選ぶと、そのキャラまでの取り方も出ます。
    5. シードの保存: このブラウザに自動保存されます。別の端末で使うときのために、上部のシードの数字をメモしておくと安心です(数字を「シード(現在)」に入れれば同じテーブルが出ます)。

    AとBのトラック、R(被り)とG(確定枠)

    • あなたは常に A の一番上(1A) にいます。単発で引くと 1A → 2A → 3A… と進みます。
    • B はもう一方のトラックです。乱数を「半回し」する操作、つまり 11連・15連の確定枠(G) と レア被りの引き直し(R) が起きたときに A↔B が入れ替わります。セルの「→5B」は、そこを引いた後の位置です。
    • レア被り: 直前に引いたレアキャラと同じレアキャラが出そうになると、ゲームは乱数を追加で1回使って別のレアに引き直します。セルの「被り時」がそのキャラです。
    • セルの 祭:超激レア は、同じ位置を超ネコ祭・極ネコ祭で引くと超激レアになることを示します(シードは全ガチャ共通なので、ガチャを切り替えて評価を見比べられます)。

    仕組み

    • セーブデータにはガチャ用の乱数の種(シード)が1つあり、レアガチャを引くたびに決まった計算式(xorshift32)で進みます。チケットでもネコカンでも、どのイベントでも同じシードを使います。
    • 1回引くごとに乱数を2回使います(レアリティ → そのレアリティの何番目か)。確定枠と被りの引き直しは1回だけ使うため、半分ずれてトラックが入れ替わります。
    • 排出率は 1/10000 単位(通常 69.7 / 25 / 5 / 0.3%、超ネコ祭・極ネコ祭 64.7 / 26 / 9 / 0.3% など)で、イベントデータの値をそのまま使っています。
    • 計算方法とデータは godfat/battle-cats-rolls(Apache-2.0)の Ruby 実装と日本版データを移植・同梱したもので、同じシードを入れれば同サイトと同じテーブルになります。

    注意

    • 非公式ツールです。ゲームのアップデートで計算式やデータが変わると合わなくなることがあります。
    • ガチャに新しい超激レアが追加されると超激レアの並びが変わり、超激レアの位置のキャラが入れ替わることがあります(レア・激レアの位置は基本的に変わりません)。
    • 同じキャラが複数回入っているガチャでは、どちらを引いたか判別できないため見つかりにくいことがあります。
    • プラチナ・レジェンドガチャも同じシードを使いますが「確定枠」ではありません(1回につき乱数2回)。
    • 開催期間はデータ上の日付です(実際の切り替えは11:00が多いです)。このページは通信を一切行わず、すべて端末内で計算します。
